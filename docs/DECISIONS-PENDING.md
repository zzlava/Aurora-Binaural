## N2 导出响度策略（2026-10-18 已决定：采用 Claude 推荐——默认 D，B/C/不处理 作为可选项）
P1c 为避免限幅压扁低频，在处理前加入最多 10.5 dB 的输入余量，导致响度母带导出后比原曲轻约 6–7 dB。可选方案：
- A. 保持现状：动态与低频完整，需要用户自己调大音量（推荐作为默认）。
- B. 匹配原曲响度：导出时补回增益，由限幅器控制峰值，低频会被部分压扁。
- C. 目标响度：例如 −14 LUFS（流媒体标准），提供选项。
建议：默认 A，导出面板增加“响度：保持动态 / 匹配原曲 / −14 LUFS”下拉框。
- 补充（《泡沫》实测，原曲 −13.2 LUFS / −2.7 dBTP）：V1/V2/V3 输出 −21.1 至 −21.7 LUFS，真峰值只有 −5.5 至 −6.0 dBTP，固定余量对这首歌多留了约 5 dB。**新增方案 D（Claude 推荐作为默认）：导出时做纯增益的峰值归一化，把真峰值提到 −1 dBTP。**这一步不经过限幅器、不压缩低频，《泡沫》可以因此找回约 5 dB 响度。B/C 作为可选项保留。
