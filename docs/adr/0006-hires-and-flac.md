# ADR 0006：FLAC 与高解析度音频

日期：2026-10-17
状态：已接受（用户问："能否支持 FLAC 等高解析度音频"）

## 决定

1. **格式**：输入和输出都支持 FLAC（16／24 bit）、WAV（16／24 bit 和 32 bit float）、ALAC（M4A 封装）以及 AIFF；原有的 AAC 和 MP3 保留。导出时尽量保留原文件的元数据（标题、艺术家、专辑、封面）。
2. **采样率**：输入支持 44.1／48／88.2／96／176.4／192 kHz。导出的采样率可选 **"与源文件相同"（默认）**、44.1、48、96 kHz。
3. **内部处理固定为 48 kHz、32 bit float**：高采样率的输入用高质量重采样器（soxr，VHQ 档）降到 48 kHz 处理，导出时再升回目标采样率。
   - 理由：空间听感的线索（HRTF、ITD/ILD、反射）都在 20 kHz 以下；现在的 HRIR pack、固定均衡和预设也都按 48 kHz 设计和校准。以 96 kHz 原生处理时，需要重新做 HRIR pack 和均衡，并重新校准听感，而可闻的收益几乎没有。
   - 代价：24 kHz 以上的超声内容不会经过空间处理（经过一轮重采样后会被滤掉）。这一点在文档和报告里写清楚，不宣称"原生高解析度空间处理"。
   - 以后如果确实需要，可以把"96 kHz 原生处理"作为单独的实验项：SADIE II 提供 96 kHz 的数据。
4. **时间线**：重采样后，样本数按 `round(n × 目标采样率 / 48000)` 计算，并保证与源文件时长一致（误差不超过 1 个样本）；报告中写明原始采样率、处理采样率、输出采样率和样本数。
5. **位深**：输出 16 bit 时加 TPDF 抖动；24 bit 时加不加抖动可选（默认不加）；32 bit float 不加抖动。
