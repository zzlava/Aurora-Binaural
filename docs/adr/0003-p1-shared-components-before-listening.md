# ADR 0003：P1 先实现与路线无关的共用组件

日期：2026-10-17
状态：已接受（Claude 决定）

## 背景

P0 技术验收已经通过，但听感关（U2）要等用户回来试听。候选的路线 B 和 C 共用低频分频、STFT 上混、对象 HRTF、早期反射、FDN 和音色保护；C 只是在 B 的基础上多一个 Ambisonics 床。

## 决定

1. **P1-a**（现在开始）：Rust 核心先实现路线 B 用到的全部组件，以及块处理框架和 Python 绑定，并与 P0 原型做数值回归对照。
2. **P1-b**（听感关之后）：Ambisonics 床、完整 3 阶旋转、MagLS，以及按听感结论定版的默认参数。
3. 如果听感关否定了路线 B 的基本结构（例如空间感不足，需要换一种上混方法），P1-a 中的分频、卷积、HRTF 加载、FDN、早期反射、绑定框架仍然可以复用，返工只涉及上混模块。
4. 应用层继续推进 P3（API 与 Worker），这部分和算法无关。

## 关于 P0 原型的一个提示

原型的 `process_file` 是对整段音频计算后再分块的，并不是真正的流式处理。P1 的 Rust 核心必须是真正的逐块流式，在任何块大小下与原型输出的差异都要在容差以内。
