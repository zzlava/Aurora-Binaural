# P1b-cursor-01：路线 V 的 5 个用户宏控件（运行时可调，实时安全）

状态：已编写；在 P0-cursor-07 之后派发
执行方：Cursor（模型 grok-4.7-high）　分支：`agent/cursor/P1b-01`（基于最新 main）
时间上限 120 分钟；每完成一个子项就先提交一次。
依据：ADR 0005

## 任务

1. 在 `presets/route_v.toml` 中加入宏控件映射：
   - `strength`、`width`、`height`、`room`、`voice_distance` 各自映射到哪些内部参数，取值范围 0–1，映射成线性或分段曲线。
   - 每个预设各写一组宏控件默认值，并保证**用这组默认值展开后，与当前预设的内部参数完全相同**（V3 的输出逐位不变）。
2. 原型和 Rust 核心都实现"宏控件 → 内部参数"的展开。Rust 的 `set_params` 接受宏控件；参数改变时，在 20–50 ms 内平滑过渡，过程中不分配内存，也不能出现可闻的咔嗒声：
   - 增益平滑插值；
   - 方位和仰角变化时，HRIR 做交叉淡化；
   - 混响参数的变化不能造成不连续。
3. Python 绑定提供 `set_controls(dict)`，以及展开后的 `effective_params()`（用于写进报告）。原有接口保持兼容。
4. 测试：
   - 每个控件取 0、0.5、1 时，IACC 或 DRR 的变化方向要符合预期：宽度增大 → IACC 下降；房间感增大 → DRR 下降；人声距离增大 → 人声的 DRR 下降；头顶感增大 → 高度层能量上升。
   - 处理过程中途改变控件取值：输出没有 NaN，不超过真峰值上限，也没有阶跃（用一阶差分的峰值来检测）。
   - 默认值与预设逐位一致；块大小模糊测试照旧通过。
5. 报告写在 `qa/p1/cursor/REPORT-v4.md`。只修改 `core/`、`prototypes/`、`presets/`、`qa/p1/cursor/`。在本分支提交，不要推送。
