# P0-cursor-05：固定均衡的泛化（留出素材）与目录整理

状态：已派发（2026-10-17）
执行方：Cursor（模型 grok-4.7-high）　分支：`agent/cursor/P0-03`（基于最新 main）
前置：阅读 `qa/p0/ACCEPTANCE-cursor-04.md`。

## 时间与迭代上限（硬性）

- 总时长不超过 90 分钟。均衡设计和参数调整最多迭代 6 轮。每完成一个子目标就先提交一次。
- 达不到门槛时，不要无限迭代：把最好的一版和差距写进报告，然后结束。

## 任务

1. **目录整理（先做，单独提交）**：用 `git mv` 把 `qa/tools/` 下你新建的 `design_fixed_eq.py`、`diagnose_route_b.py`、`measure_raw_engine.py`、`render_samples_v2.py` 移到 `qa/p0/cursor/tools/`，并修好引用路径。`qa/tools/` 归 Claude，以后不要在里面新建或修改文件。
2. **留出素材**：从 `data/assets/src/` 的原始文件里截取训练集之外的片段（例如钢琴曲 70–100 秒、人声和雨声中没用过的部分），再新增至少 1 段**风格不同**的 CC0 或 CC BY 立体声音乐（例如有鼓和人声的流行或电子乐，不超过 30 秒）。登记来源和哈希。这些素材**只能用于验证，不能参与均衡设计**。
3. **均衡设计只用合成信号**：固定 FIR 只根据粉噪探测信号（单声道复制、部分相关、不相关）的统计来设计，不能再向真实素材偏移；如果需要，可以加上平滑约束（例如 1/3 倍频程平滑，或限制相邻频带的斜率）。
4. **门槛**（全部用引擎直接输出、只做宽带增益匹配来测量）：
   - 训练素材和留出素材：40 Hz–16 kHz 的 1/3 倍频程偏差（去掉整体电平差）**≤ ±3.5 dB**。
   - 音乐 IACC 下降：强度 0.4 时 ≥ 0.08，强度 0.8 时 ≥ 0.15（训练和留出的音乐都要满足）。
   - 人声强度 0.4 时 IACC ≥ 0.85。
5. 如果改变了均衡或参数，就用 `qa/p0/cursor/tools/render_samples_v2.py` 重新生成 `samples_v2`（同样只做宽带增益匹配），并同步更新 `presets/p0_draft.toml`。
