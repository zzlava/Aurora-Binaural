# P1d-cursor-01：古典/现场录音低频损失（单声道低频求和）与 700 Hz 凸起

状态：已派发（2026-10-17）
执行方：Cursor（grok-4.7-high）　分支：`agent/cursor/P1d-01`（基于最新 main，已含 P1c）
时间上限 120 分钟；每完成一个子项就先提交一次。允许改 core/ 与 presets/。

## 背景（Claude 测量，新核心 P1c，V1/V2/V3 强度 1，全曲已做 BS.1770 对齐）
- 用户素材：卡拉扬／维也纳爱乐《卡门》第一幕（96k/24，间隔式话筒的厅堂录音）。三种预设在 50–160 Hz 都比原声低 **4–5.7 dB**，25–40 Hz 低约 3 dB。
- 《泡沫》（流行乐，低频本身是单声道）低频反而高约 +1 dB。
- 原因（已验证）：原声在 30–80 Hz 的 L/R 相关系数，卡门为 **−0.17**，泡沫为 0.985；把卡门的低频做 (L+R)/2 单声道求和，30–80 Hz 损失 **−3.5 dB**，80–160 Hz 损失 −2.2 dB。路线 V 在 crossover（150 Hz）以下走单声道直达声路径，相关性低的低频被抵消掉了。P1c 的固定搁架是按流行乐调的，会让流行乐的低频偏多。
- 另一个问题：两首歌在 635–800 Hz 都有 +1.6～+3.2 dB 的凸起（卡门最明显），lf 试听样本里同样存在，可能是某个固定 EQ、早期反射或 HRTF 均衡造成的着色。

## 任务
1. **低频保能量**：在 crossover 以下保留能量，不再简单做 (L+R)/2。可选方案（由你评估后选择）：(a) 低频保持立体声，L→左耳、R→右耳，或经过前方 ±30° 的 HRTF 对；(b) 按相关性自适应的功率补偿，增益 = sqrt(2/(1+ρ))，用平滑的 ρ 估计，并设上限，不能造成泵动；(c) 中/侧分解：M 走单声道直达，S 以立体声保留。要求：卡门的 31.5–160 Hz（相对 1 kHz、等响度条件下）在 ±1.5 dB 以内；泡沫、holdout_electronic、粉噪不劣于 P1c 的结果；单声道低频（L=R）的输出仍然相干，L/R 相关 >0.98。
2. **重新评估 P1c 的低频搁架**：方案 1 完成后，把搁架减小或去掉，以几种素材的整体表现为准。
3. **700 Hz 凸起**：找出 635–800 Hz 凸起的来源（固定 EQ、早期反射梳状、FDN 模态、HRTF 均衡，逐路径关闭来定位），修正到这三首素材的 1/3 倍频程偏差都 ≤ ±1.5 dB。
4. 强度 0 时仍为逐位旁路；process 中零分配；可变块长 fuzz 测试通过；时延变化写入报告。
5. **测试素材**：`qa/listen/carmen/carmen48.flac` 与仓库根目录的 `paomo.flac` 是用户本机的版权素材，只能在本机读取，**不得提交、不得复制进仓库**。报告中只写测量数字。另外请生成一段合成的“间隔式话筒厅堂”测试信号（两路低频带通噪声，ρ≈0，加相干的中高频），放进 data/assets，作为可入库的回归素材。
