## 背景

- v3（路线 B）听感关**未通过**：用户觉得"最高强度也与原声差别不大，没有空间感"（`qa/p0/LISTENING-01.md`）。
- 第 1 轮校准，用户的选择："**要 C 的头外感，再宽一点，不要转圈，最好能感觉头顶也有音响**"。
- 参照实现：`qa/tools/calibration_anchors.py`，其中的 C、F、G、H 是 Claude 的快速参照（只读，不要修改）。第 2 轮（F/G/H）的听感结果出来后，用来确定最终参数。所以这次要做成**可以调参的**引擎。
- 默认 HRTF 改为 **SADIE II D1**（ADR 0004）；KU100 只做对照。

## 目标：在 `prototypes/aurora_p0/` 中新增路线 "V"，保留路线 B，不要破坏它

1. **上混**：沿用 P0 中按相干性做的直达／环境分离。
2. **虚拟音箱布局**（全部写进预设 TOML，作为参数）：
   - 前方一对 L/R：方位角 `front_az`（默认 40°，范围 30–60°），承载直达成分。
   - 宽声场一对：±`wide_az`（默认 90°），承载环境成分，加去相关。
   - 环绕一对：±`surround_az`（默认 130°），承载环境成分，相对宽声场对有额外延时。
   - **高度层 4 只**：仰角 `height_el`（默认 45°），方位角 ±45°、±135°；承载环境成分，外加少量直达成分（`height_direct_db`）。
   - 每一层都有独立的增益参数：`wide_db`、`surround_db`、`height_db`。
3. **房间**：鞋盒房间的早期反射要包括天花板和地板（而不只是水平面的反射），按方向用 HRTF 渲染；晚期混响用 FDN，`t60` 和 `room_db`（直达声与混响能量比）可调。头外感主要靠这两项，默认值以 C／F 的听感为参照。
4. **强度**：`strength` 0–1 按比例同时缩放 宽声场／环绕／高度／房间 四项的增益，以及 `front_az` 从 30° 到默认值的展开。0 时旁路。不允许用干湿混合实现。
5. **固定均衡**：方法同 P0-05，只用粉噪统计设计，以 SADIE 为准。路线 V 的音色门槛**放宽到 ±5 dB**（用户更看重空间感）。
6. **限制器**：原型链路末端加一个简单的真峰值保护（−1 dBTP），避免样片削波。
