# P1c-cursor-01：路线 V 低频不足——余量管理与低频平衡

状态：已派发（2026-10-17，P1b 验收通过后）
执行方：Cursor（grok-4.7-high）　分支：`agent/cursor/P1c-01`（基于最新 main）
时间上限 120 分钟；每完成一个子项就先提交一次。允许改 core/ 和 presets/；本任务允许输出改变，但必须给出前后对比。

## 背景（Claude 测量，2026-10-17）
用户反馈：“声场广了，但低频起不来”。测量对象为 V3、强度 1.0、holdout_electronic 前 20 秒（这是一首响度很高的母带，峰值 0 dBFS，RMS −10.2 dBFS）。各频带增益为“输出减输入”：

| | 峰值 | RMS 增益 | 40 Hz | 63 Hz | 100 Hz | 1 kHz |
|---|---:|---:|---:|---:|---:|---:|
| 限幅器关 | +8.0 dBFS | +2.5 | +1.2 | +1.5 | +3.4 | +4.0 |
| 限幅器开 | −1.4 | −1.03 | −3.2 | −1.8 | −1.8 | +1.2 |

real_music（安静的母带，峰值 −10 dBFS）不触发限幅器，40 Hz 相对 1 kHz 只低约 1.7 dB。
结论：**(1) 主因**是商业响度母带经空间处理后峰值增加约 8 dB，限幅器压下约 9 dB，低频能量大，被压得最多；**(2) 次因**是早期反射和 FDN 的能量集中在中频，而低于 crossover 150 Hz 的部分只走直达声，频谱整体向中频倾斜，40 Hz 相对 1 kHz 约 −2.8 dB。

## 任务
1. **自动余量（输入预衰减）**：在空间处理之前，按强度和预设加入确定性的输入增益，估算峰值增长的上限（可从各条路径的增益之和离线推导，也可用粉噪与冲激离线标定后写入 TOML），使响度母带（参考 holdout_electronic 和一段 −9 LUFS 的流行母带合成样本）在强度 1.0 时，限幅器最大增益衰减 ≤ 2 dB，95% 时间 ≤ 0.5 dB。在 render report 中输出 `headroom_db` 字段。强度为 0 时仍须逐位旁路。
2. **低频平衡**：在直达声、低于 crossover 的低频路径上加入随强度变化的补偿（低搁架，或让低频路径的增益跟随空间路径的总能量增益），使粉噪和 holdout_electronic 在限幅器关闭时，31.5–160 Hz 各 1/3 倍频程相对 1 kHz 的偏差在 ±1 dB 以内。低频保持单声道、相干，L/R 相关系数 >0.98，不能让低频变宽或变糊。
3. **限幅器**：检查其 attack/release 与 lookahead，避免对低频产生明显的增益泵动。如需修改，用 1 kHz 测试音叠加 40 Hz 正弦脉冲，测互调与增益调制并写入报告。
4. 实时安全：process 中零分配，可变块长 fuzz 测试通过；时延变化写入报告。
5. 输出试听样本（不入库，路径列入 gitignore）：qa/p1/cursor/lf/ 下放 holdout_electronic、real_music 各 20 秒，分别为原声、当前 V3、新版 V3，三者已做 BS.1770 等响度匹配。另生成一个 index.html，使用单个 audio 元素切换音源（避免之前“播放下一个没声音”的问题）。
