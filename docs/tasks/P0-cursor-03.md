前置：先阅读 `qa/p0/REVIEW-cursor-02.md`。P0-cursor-01 的规则继续有效。工作目录和分支同前（`.agents/cursor/`，`agent/cursor/P0-01`）。

## 必须完成

1. **D8 低频**
   - 找出分频点附近（100–200 Hz）以及 50–63 Hz 的低频增益来源，并修复。逐项排查：分频滤波器的互补性（LR4 等）、处理路径是否已经高通、HRTF／均衡的低频增益、FDN 和早期反射的低频能量。
   - 验收：真实素材（人声、音乐、环境音）用路线 B、强度 0.4 处理后，40 Hz–16 kHz 每个 1/3 倍频程相对原声的偏差（去掉整体电平差后）在 ±3 dB 以内。
   - 单独测试分频器：低频与高频重新合成后，20 Hz–20 kHz 的幅度偏差 ≤ ±0.5 dB。
2. **D9 复现入口**
   - `run_p0.py` 支持 `--block-size N`、`--only <素材类别>`、`--route A|B|C`、`--strength x`、`--hrtf thk_ku100|sadie2_d1`、`--eq frontal|diffuse`、`--out <目录>`。
   - 文档里写明一条命令：在 64／256／1024 三种块大小下渲染同一素材，并输出相互之间的最大误差。
3. **补充样片**
   - 生成 SADIE II + 正前方均衡 + 路线 B 的完整样片（人声、音乐、环境音，强度 0.4 和 0.8），用于和 KU100 做听感对比（涉及许可证决策）。
   - 加上路线 B 在强度 0.2 和 1.0 下的音乐样片，方便判断强度范围是否合适。
