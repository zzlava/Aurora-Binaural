# P1d-cursor-01：低频保能量与 700 Hz 凸起

分支 `agent/cursor/P1d-01`。测量：48 kHz，V3，强度 1，宽度 0.5，高度 0.75，房间 0.5，人声距离 0.25，限幅器关。表里的数字是「输出减输入，再减去 1 kHz 那一档的差」。宽带响度对齐是一个常数增益，不改变这个相对值。改前是 P1c 核心上各素材开头 24 秒；改后的验收用整段（卡门 129.7 s，泡沫 273.4 s，holdout 25 s，粉噪 400 s、种子 3）。

## 1. 低频怎么留

crossover（150 Hz）以下不再做 `(L+R)/2`。左声道进左耳，右声道进右耳，两边用同一组搁架和峰值系数、各自的状态。单声道（L=R）因此仍然逐样本相同。

没有走前方 ±30° 的 HRTF。150 Hz 以下同侧和对侧 HRTF 的幅度都接近 1、相位也接近，两只喇叭在耳朵里加起来还是 `(L+R)`，抵消会回来。也没有用 `sqrt(2/(1+ρ))` 做整段低频的功率补偿：卡门 30–80 Hz 和 80–160 Hz 的相关系数不一样，一个增益补不齐，而且增益跟着音乐走会泵。

中/侧分解如果侧声道按原电平保留，左 = M+S、右 = M−S，和「左进左耳、右进右耳」是同一条信号。

搁架仍是 90 Hz、强度 1 时 +2.4 dB，180 Hz 的峰值仍是 −2.2 dB、Q 0.8。整段泡沫和 holdout 的深低频已经在 0 dB 附近，粉噪和 P1c 一样；把搁架拿掉会把卡门 50–80 Hz 重新拉低。所以搁架留下，不加大。

卡门 125–160 Hz 在立体声直通之后仍比 1 kHz 低大约 4 dB。这一档有一半能量在 crossover 以上，低通路上的均衡够不着。混音完成之后加了一个峰值（155 Hz，满增益 +4.6 dB，Q 1.3）。检测器只看 80 Hz 高通后的低频，ρ ≥ 0.95 时增益为 0，ρ ≤ 0 时给满。时间常数 0.8 s，再限制在每秒 4 dB。粉噪 ρ = 1，这一级是 0 dB，所以粉噪不跟着抬。

60 Hz 反相正弦的单耳功率不再被抵消（原来会掉到只剩高通泄漏）。单声道低频的左右相关，粉噪整段是 0.9999。

## 2. 700 Hz 凸起从哪来

定位时低频已经改成立体声直通，搁架还在，相关性峰值和高度衰减都还没开。各 16 秒，仍相对 1 kHz：

| 关掉的路径 | 卡门 630 | 卡门 800 | 泡沫 800 | holdout 800 |
|---|---:|---:|---:|---:|
| 都不关 | +2.81 | +3.63 | −0.34 | +1.07 |
| 固定 EQ | +2.29 | +3.19 | −0.72 | +0.44 |
| 早期反射 | +3.15 | +3.46 | −0.43 | +2.30 |
| 后期 FDN | +2.83 | +3.64 | −0.36 | +1.07 |
| 宽 + 环绕 + 高度 | −1.41 | +3.70 | −0.11 | +0.22 |
| 只关高度 | +2.08 | +1.85 | −0.59 | −0.43 |
| 只留正前方（无床、无房间） | −7.58 | −2.35 | −15.73 | −1.27 |

固定 EQ 在 630 / 794 Hz 相对 1 kHz 大约多 +0.5 dB，对得上「关掉 EQ」之后凸起只掉这 0.5 dB。早期反射和 FDN 关掉之后凸起还在。只留正前方时凸起消失，800 Hz 反而偏暗。

整床关掉时 800 Hz 的相对值还在 +3.70，因为 1 kHz 跟着床一起掉。只关高度，卡门 800 Hz 从 +3.63 落到 +1.85，500 Hz 从 +2.38 落到 +0.06；泡沫 800 Hz 只从 −0.34 到 −0.59。关掉宽声道，卡门 800 Hz 升到 +4.60；关掉环绕仍是 +3.13。凸起是高度层 HRTF 的着色，不是梳状滤波，也不是 FDN 模态。正相关的流行乐能量留在正前方，几乎碰不到这一刀。

所以只在四只高度扬声器的 HRIR 上加一个峰值衰减：780 Hz，−12 dB，Q 1.2。正前方、宽、环绕、早期反射都不动。时延不变，因为对齐用的是正前方 HRIR 的峰。

## 6. 时延和实时

搁架、相关性峰值、高度 HRIR 上的峰值都不增加整数时延。和 P1c 相同：

| 状态 | 时延 |
|---|---:|
| 强度 0 旁路 | 0 |
| 限幅器关 | 1197 样本 |
| 限幅器开 | 1229 样本 |

`process` 里的相关检测、双声道低频延迟和高度 HRIR 染色都不分配内存。`cargo test -p aurora-dsp --lib` 52 项通过，其中有可变块长 fuzz（路线 V，块长上限 512 和 4096）、零分配，以及强度 0 的逐样本旁路。
