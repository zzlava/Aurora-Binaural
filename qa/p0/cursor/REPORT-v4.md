# P0-cursor-06：路线 V 样片 v4

测量日期：2026-10-17。分支 `agent/cursor/P0-04`。种子 `20261016`，48 kHz，块长 256。路线 V，正前方均衡，方向功率补偿开。默认 HRTF 是 SADIE II D1；KU100 只做 V2、强度 1.0 的对照。

样片在 `qa/p0/cursor/samples_v4/`。每条先走引擎（固定均衡和 −1 dBTP 真峰值保护都开着），再做一次宽带响度匹配到 −20 LUFS。IACC 和 1/3 倍频程偏差取的是匹配之前的 `Processor.process_file` 输出。整体增益不改变这两项。原声对照也按同一响度配了一份，文件名带 `dry_lufs20`。数值在 `qa/p0/cursor/metrics_v4.json`。

第 2 轮校准以这一句为准：G 更合适，但人声要更近。所以 V2 是默认预设。V1 是同一套空间、人声更远，用来确认“近”听得出来。V3 是 V2 再加一档高度。

## 1. 人声是不是更近

两条独立的直达混响比，都只在人声上算。

**总线 DRR** 是引擎内部的能量比：中置那一对虚拟音箱（HRTF 之后）除以只由这段中置、再乘上 `direct_room_send_db` 之后送进早期反射和 FDN 的能量。G 没有这条总线，对照用的是它自己的分量：`place(L, +45) + place(R, −45)` 除以早期反射（−3 dB）、晚期混响（−6 dB）和天花板混响（−12 dB）。G 用的是 KU100，和校准脚本一致。

**投影 DRR** 是同一段估计，用在最终双耳波形上：200 Hz–3.5 kHz 的中置声道，对齐到原声之后，相干部分比上剩下的部分。HRTF 自己的染色也留在分母里，所以绝对值比总线 DRR 低。V2 的 KU100 版和 G 用的是同一套估计、同一只 HRTF。

| 版本 | 总线 DRR | 投影 DRR |
|---|---:|---:|
| G（KU100，校准参照） | 2.21 dB | 2.98 dB |
| V1 强度 1.0，SADIE（人声更远） | 0.83 dB | 0.93 dB |
| V2 强度 1.0，SADIE | 8.40 dB | 3.89 dB |
| V2 强度 1.0，KU100 | 8.07 dB | 5.57 dB |
| V3 强度 1.0，SADIE | 7.43 dB | 3.73 dB |

V2 比 G 更干。同一只 KU100 上，投影 DRR 高 2.6 dB，总线 DRR 高 5.9 dB。V2 比 V1 的总线 DRR 高 7.6 dB，和预设里 −8 dB 的房间发送差在同一档。人声 IACC 仍在 0.94–0.97，声像没有被拉散。

强度 0.5 时房间再小一半，V2 人声总线 DRR 升到 14.4 dB。近和远的差别在两档强度上都在。

## 2. 信号怎么走

相干性上混仍是 P0 那一套（`streaming_upmix_file`，环境全部进非相干床，直达不漏到床上）。高频不做“收回到正前方”的渐变，否则高度层会丢掉耳廓用的那一段频谱。

- 最靠近 0° 的那个扇区是人声主体。它渲染在 ±`center_spread_deg`，距离 `center_distance_m`。比 HRTF 测量距离（1.5 m）更近时，加一个最高 4 dB 的低频抬升，再加上由耳间距算出来的低频视差 ILD。这个 ILD 在 0.9 m、±28° 时不到 1 dB，近的感觉主要来自房间发送和略窄的声像。
- 其余直达扇区落在 ±`front_az` 里，不加近场。
- 非相干成分进宽声场（±`wide_az`，去相关）、环绕（±`surround_az`，再晚 `surround_delay_ms`）、四只高度音箱。高度层里只有很少的直达：侧向直达按 `height_direct_db`，中置按 `center_height_db`（V2 是 −22 dB），而且只进前上方那一对，晚 9 ms。
- 房间是鞋盒的一阶镜像源，Allen & Berkley 的奇偶公式，天花板和地板各有一条被留住，再按方向卷 HRTF。仰角 ≥ 25° 的抽头再加 `ceiling_db`。晚期是原来的种子 FDN，`t60` 可调。路线 B 仍走它原来的镜像函数，没有改。
- 150 Hz 以下保持单声道、不进房间，延迟对齐到上混加 HRIR 峰。
- `strength` 为 0 时整段旁路。大于 0 时，宽声场、环绕、高度、早期、晚期的幅度按强度线性缩放，`front_az` 从 30° 张到预设值。没有干湿混合。人声距离和 `direct_room_send_db` 不跟强度走。
- 固定均衡是 512 点最小相位 FIR，设计方法同 P0-05：三条粉噪（双单声道、ρ≈0.6、不相关），1/3 倍频程误差取平均再取反，钳在 ±5 dB。真实录音不参与设计。SADIE 是设计参照；KU100 只配了 V2。
- 均衡之后做真峰值保护，门槛 −1 dBTP。响度匹配若再次顶到门槛，只再乘一个标量。

V2 在强度 1 时的早期反射（相对听者）：地板 10.5 ms、仰角 −44°；天花板 11.4 ms、仰角 +48°；侧墙 ±60°、15.4 ms。几何增益大约 0.2，所以 `early_db` / `room_db` 写成正数，听感才落到 C／G 那一档抽头电平，而不是 v3 那种几乎听不见的房间。

## 3. 参数（强度 1 的终点）

三组预设共用 `[layout]`，下面只列不同的地方。强度 0.5 时 `front_az` 是 37.5°，五路空间增益再低 6 dB；V2 的人声张角仍是 28°。

## 4. 迭代

只动空间增益，不按真实录音改均衡曲线。

1. 初值贴近 G 的标称增益（早期 −1 dB，晚期 −4 dB，宽声场 −3 dB）。人声 V2 的总线 DRR 有 17 dB，但房间比直达低大约 20 dB，头外化不够；音乐上的展宽也偏弱。
2. 早期提到 +7 dB、晚期提到 +4 dB，宽声场 +1 dB，环绕 −4 dB。人声 V2 总线 DRR 落到 8.4 dB，V1 落到 0.8 dB，G 是 2.2 dB。空间还在，人声明显更干。停在这里。

粉噪曲线本身的峰值，SADIE 上 V2 是 3.83 dB（强度 0.5）和 3.80 dB（强度 1.0），没有顶到 ±5 dB 的钳位。

## 6. 已知局限

通用 HRTF 的高度感不可靠。SADIE II D1 也是 KU100 假头，耳廓凹槽是那一只头的，不是听者的。仰角 45°–55° 常常被听成“更亮”或“有点高”，而不是稳定的头顶音箱；±135° 还有前后颠倒。四只高度音箱和天花板反射只是把能量送到这些方向，不能保证每个人都听成头顶。

±1 ms 的 IACC 量不到晚期混响，也量不到高度。人声故意保持高相关。音乐在强度 0.5 时 IACC 甚至比原声略高：相干部分被收到较窄的前方，而宽声场和房间只有一半增益，盖不住原声里已经有的宽度。强度拉到 1.0，音乐 IACC 从 0.624 降到 0.520。

近场 ILD 是视差的一阶近似，不是近场 HRTF。0.9 m 上它很轻。

FDN 冲激响应最长大约 1 秒，`t60` 再拉长也不会把尾巴铺得更远。
