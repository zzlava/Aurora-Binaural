# P0-cursor-05：固定均衡只按粉噪设计

测量日期：2026-10-17。分支 `agent/cursor/P0-03`。种子 `20261016`，48 kHz，块长 256，路线 B，预设 `room`，正前方均衡，方向功率补偿开。

指标来自 `Processor.process_file` 的直接输出，对照原声。没有响度匹配，也没有 `diagnostic_timbre_guard`。入口是 `qa/p0/cursor/tools/measure_raw_engine.py`。每个 1/3 倍频程的数值在 `qa/p0/cursor/metrics_v3.json`。下表「最大偏差」是 40 Hz–16 kHz、去掉整体电平差之后的绝对值最大者。门槛是 `≤ 3.5 dB`。

IACC 是 ±1 ms 内归一化互相关峰值的绝对值，与 `qa/tools/p0_metrics.py` 一致。

结论：人声中置、训练音乐和留出钢琴的展宽达到门槛。音色没有全部落进 ±3.5 dB。差得最多的是 SADIE 上训练音乐 8 kHz（6.12 dB）和留出钢琴 1.6 kHz（4.97 dB）。留出电子乐在强度 0.8 的 IACC 下降也不够。下面是这一版的完整数，没有再改曲线。

## 2. 门槛对照

音乐类包含训练音乐、留出钢琴、留出电子乐。强度 0.4 的 IACC 下降要 ≥ 0.08，强度 0.8 要 ≥ 0.15。人声强度 0.4 的 IACC 要 ≥ 0.85。音色是全部 50 行都要 ≤ 3.5 dB。

达到的：

- 人声两个 HRTF、五档强度，音色最大 2.73 dB。强度 0.4 的 IACC 是 KU100 0.945、SADIE 0.927。
- 训练音乐的 IACC 下降：KU100 0.4 为 0.109、0.8 为 0.229；SADIE 0.4 为 0.159、0.8 为 0.298。
- 留出钢琴的 IACC 下降：KU100 0.4 为 0.115、0.8 为 0.206；SADIE 0.4 为 0.161、0.8 为 0.228。
- 留出电子乐强度 0.4：KU100 下降 0.116，SADIE 下降 0.110。音色全部 ≤ 2.49 dB。
- KU100 环境音五档都 ≤ 3.45 dB。

## 4. 均衡怎么来的

运行时仍是 512 点最小相位 FIR，左右耳同一条。系数在 `presets/p0_draft.toml` 的 `[room.fixed_eq]`，按 HRTF 和强度各一行，中间强度在 dB 上线性插值。`surround` 和 `orbit` 这轮没有重做。

设计脚本 `qa/p0/cursor/tools/design_fixed_eq.py` 只渲染三条 4 秒粉噪，`apply_fixed_eq=False`：

- 双单声道
- 相关系数约 0.6
- 完全不相关

每条去掉 40 Hz–16 kHz 的 1/3 倍频程中位数。三个误差取平均，增益是这个平均的相反数，再钳在 ±6 dB。真实文件不读入这条公式。脚本里的 `--adjust` 会直接退出，避免再把交付文件收进曲线。

房间的 `bed_peak_db` 从 6 改成 0。这个峰只加在宽像和后方床层上，不相关粉噪在 1.25 kHz 被抬亮，正前方的钢琴没有跟着抬。平均取反之后就会去切钢琴。床层和直达的公共染色留给粉噪曲线自己去补。

试过、没有留在预设里的做法：

1. 三条平均之后再做 3 点平滑，相邻 1/3 倍频程斜率限制 2.5 dB。2 kHz 上只有部分相关那条探针是暗的，平滑把这档增益抹平，预测残差更大。
2. 侧向改成同一延时、左右反相，想让单声道下混消掉梳状。音乐强度 0.4、KU100 的 IACC 下降掉到 0.040，音色也更差。已改回左右两条不同延时。
3. 把 `hf_direct_end_hz` 收到 5500 Hz，想让 6.3 kHz 以上都走正前方。SADIE 8 kHz 的音乐残差变得更大，已改回 8000 Hz。

粉噪曲线在 2 kHz 的 KU100 增益随强度是 +0.86、+0.34、−0.43、−0.72、−0.90 dB。强度上去之后探针自己要切 2 kHz，音乐和钢琴的洞就更暗。SADIE 8 kHz 的增益大约是 −1.4 到 −1.8 dB，加在一块已经偏暗的泄漏读数上。
