# P0 听感试听（v2）

样片来自 `qa/p0/cursor/samples_v2/`：引擎直接输出，只做了宽带响度匹配。v1 样片已作废。

1. 在 Finder 中打开 `qa/p0/listening/index.html`（用 Safari 或 Chrome），戴上耳机。
2. 人声、音乐、环境音三组，每组都有原声参照，以及路线 B 在 5 档强度（0.2–1.0）× 2 个 HRTF 下的 10 个版本；可以勾选"盲听"。
3. 按 空间感／清晰度／音色自然／不疲劳 四项打 1–5 分，点"生成结果"，把文字复制给 Claude。

请特别留意：

- 侧向通路用了固定延时，会不会有"相位感"或空洞感
- 1.6–2 kHz 在其他段落上可能略凹（Claude 用留出素材测到约 −3.7 dB）
- 哪一档强度最适合作默认值
- KU100 和 SADIE II 哪个更自然（关系到许可证决策 U3）
