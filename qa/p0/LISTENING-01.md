# 听感记录 01（用户，2026-10-17）

样片：v3（`qa/p0/cursor/samples_v2/`，路线 B，固定均衡只按粉噪设计）
结论：**听感关未通过**。用户反馈："最高强度也与原声差别不大，没有空间感。"

## Claude 的分析

- 客观上两耳相关度下降 0.1–0.28，这个幅度可以测出来，但在感知上偏弱。为了把音色保持在 ±3.5 dB 以内，引擎把空间处理压得很保守：直达声占比高，房间混响少，没有运动。
- 已混好的立体声音乐，"空间感"主要来自三个因素：**头外化**（房间反射和混响）、**声场宽度和包围感**（侧方、侧后方的声源），以及**运动**。v3 这三项都很弱。
- 处理：暂停 Rust 同步（P1a-cursor-03，已取消；WIP 已保存在 `agent/cursor/P1a-02`）。先用校准锚点（`qa/p0/calibration/index.html`）确定用户想要哪一类空间感、要多强，再据此重新设定算法目标和音色容差。

## 校准第 1 轮结果（用户）

"要 C 的头外感，再宽一点，不要转圈，最好能感觉头顶也有音响。"

→ 第 2 轮校准：在 C 的基础上加宽（F），再加 4 个仰角 45° 的高度虚拟音箱和天花板反射（G），以及高度更明显的版本（H）。
注意：通用 HRTF 的高度感因人而异，误判率高。头顶感主要依赖高频频谱线索和顶部反射，要在听感上确认。

## 校准第 2 轮结果（用户）

"G 可能更适合，但是在人声时需要调得感觉更近。"
→ P0-cursor-06 修订：默认以 G 为基准，直达／中置成分少送房间、渲染得更近，空间感主要由环境成分承担。

## 校准第 3 轮结果（用户，2026-10-17）：**选择 V3**

V3 = V2（G 的空间：前方 ±45°、加宽声场、4 只仰角 45° 的高度音箱、天花板反射；人声更近）加上更强的高度层。用户试听时用的是强度 1.0。

→ **P0 听感关通过**，打标签 `p0-accepted`。默认预设改为 V3，默认强度 1.0（用户仍可以用滑块调低）。
